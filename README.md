# MonaySMP Core

A clean-room Paper plugin project for MonaySMP, inspired by the feature set visible in the supplied UltimateDonutSmp2 JAR. This project does not redistribute or modify that compiled plugin.

## Target
- Paper 26.2
- Java 25
- Java + Bedrock compatibility
- SQLite persistence
- Optional Vault, PlaceholderAPI, Floodgate, LuckPerms integrations

## Build
Run `gradle clean build` or use the included GitHub Actions workflow. The plugin JAR is produced in `build/libs/`.

## Status
Early foundation. Features are implemented in stages; a feature is not considered complete until it builds and is tested on a server. See `FEATURES.md` for the roadmap.
